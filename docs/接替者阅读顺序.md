| X/Y | FDCAN2，地址 1/2，125 kbit/s |
| Z | USART6，PC6 TX / PC7 RX，9600 8N1；不是 UART4 |
| 固定任务预设位 | X=512000，Y=0，Z=77600；移动顺序 Z、X、Y |

## 四、`frame_put` 接续检查顺序

1. 上电后确认 X/Y 自动回零成功，人工完成 Z 找零并执行 `z_zero`。
2. 用 `p2_status` 确认下视 XY 标定 `valid=1` 且 EEPROM 状态有效。
3. 用 `C552` 确认 K230_1 和 TOF3 为 `VALID/FRESH/READY`。
4. 用 `mission_status frame_put` 确认 `align=1`、Z 下降配置有效、安全位姿有效。
5. 先分别板测 `sf_observe frame_put frame`、`sf_align frame_put xy <x> <y>`、
   `sf_descend frame_put <stop_mm> <max_pulses> <dir>`、`sf_grip frame_put open` 和
   `sf_retreat frame_put`。
6. 再执行完整 `mission_start frame_put`，失败时同时保存两行 `mission_status`、`sf_status`、
   `align_status`、`xy_status`、`z_status`、`C552` 和 `motion_status`。
7. 正常链通过后，再做故障注入、`mission_abort`、全局 `abort`、掉电恢复和重复耐久测试。

1. 当前参与构建的 `App/`、`Core/` 源码和 CMake 清单；
2. `docs/legacy-migration-status.md` 中带日期的实机结果；
3. `docs/C552通信协议v3.md`、`docs/K230串口协议.md`；
4. `docs/readme/工程导航.md`、实施计划和设计方案；
5. `docs/readme/unused/`、V1/V2 协议和旧调试报告，只用于追溯。

构建验证：

```powershell
cmake --build --preset Debug
```

成功只说明软件编译和链接成立；涉及运动、串口时序和安全行为的变更仍需重新烧录并板测。
