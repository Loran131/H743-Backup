# TestH743 串口命令汇总

更新时间：2026-08-16

本文以 `App/Src/shell.c` 中当前参与构建的 `g_cmd_table` 和命令处理函数为准，汇总
USART1 Shell 可调用命令。历史文档、帮助文本和旧工程命令若与注册表冲突，以当前源码为准。

## 1. 接口与通用规则

| 项目 | 当前行为 |
|---|---|
| 串口 | USART1，PA9 TX / PA10 RX，115200 8N1 |
| 行结束 | 回车或换行提交命令 |
| 命令格式 | ASCII 文本，空格或 Tab 分隔参数 |
| 大小写 | 区分大小写；特别是 `C552` 必须大写 |
| 参数数量 | 解析器最多接收 8 个 token，包含命令名 |
| 数值前缀 | 多数新命令使用 `strtol/strtoul(..., 0)`，可接受十进制或 `0x` 十六进制；旧 SMD 命令规则见各项说明 |
| 输出 | 通过 `printf` 输出到 USART1，当前不是结构化机器协议 |
| 并发 | 自动任务、标定和手动运动受 `motion_coordinator` 所有权约束 |

当前注册命令共 91 个，另有两个内建帮助入口 `help` 和 `?`。

风险标记：

- **查询**：原则上不改变运动或持久参数。
- **控制**：会改变模式、夹爪、任务或轴状态。
- **配置**：修改 RAM 或 EEPROM 参数。
- **底层**：直接操作驱动器或测试链路，只用于人工维护。
- **急停**：安全相关停止命令。

`OK`、`QUEUED` 或底层命令已发送不一定代表动作完成。自动流程应继续查询对应的
`*_status`，C552 模式和夹爪命令必须等待匹配 `CMD_SEQ` 的 `APPLIED`。

## 2. 诊断、C552 与夹爪

| 命令 | 参数 | 类型 | 说明 |
|---|---|---|---|
| `help` / `?` | 无 | 查询 | 输出 Shell 内置帮助。 |
| `cans` | 无 | 查询 | 显示 FDCAN 状态、错误和恢复计数。 |
| `canprobe` | `[addr]` | 查询 | 探测 PD42S1；省略地址时扫描 CAN 地址范围。 |
| `C552` | 无 | 查询 | 显示链路、传感器、健康掩码、命令事务和 RX/DMA 统计。 |
| `k1_mode` | `<tag\|red>` | 控制 | 请求 K230_1 切换 AprilTag 或红色方块模式；最终以 `APPLIED` 为准。 |
| `k2_mode` | `<tag\|red>` | 控制 | 请求 K230_2 切换 AprilTag 或红色方块模式；视觉流程活动时可能拒绝。 |
| `grip` | `<open\|close>` | 控制 | 测试 C552 两路夹爪；全局锁存后拒绝。 |
| `c552_req` | `<mask>` | 配置 | 设置空闲期必需设备掩码，范围 `0..0x1F`；有运动 owner 时拒绝。 |

C552 设备掩码位：TOF1=`0x01`、TOF2=`0x02`、K230_1=`0x04`、K230_2=`0x08`、
TOF3=`0x10`。

## 7. 统一运动、安全与 P6 子流程

任务名 `<task>` 固定为：`red_pick`、`tag_put`、`red_find`、`frame_put`。

| 命令 | 参数 | 类型 | 说明 |
|---|---|---|---|
| `motion_status` | 无 | 查询 | 显示 owner、C552 必需掩码、全局锁存、停止和夹爪冻结状态。 |
| `xyz_snapshot` | 无 | 查询 | 仅在 X/Y/Z 坐标都有效、无故障且 IDLE 时返回统一坐标快照。 |
| `abort` | 无 | **急停** | 停止三轴、冻结夹爪并锁存到设备重启；不是普通流程取消。 |
| `sf_status` | 无 | 查询 | 显示当前 P6 子流程、尝试次数、Z 恢复次数、传感器和失败原因。 |
| `sf_abort` | 无 | 控制 | 取消独立 P6 子流程，非全局锁存。 |
| `sf_observe` | `<task> <red\|tag\|frame>` | 控制 | 独立执行目标观察和模式应用检查。 |
| `sf_align` | `<task> <xz\|xy> <target_x> <target_y>` | 控制 | 独立执行 XZ 或 XY 对正。 |
| `sf_blind_y` | `<task> <tof1\|tof2> <stop_mm> <pulses_per_mm> <dir>` | 控制 | 独立执行带 TOF 截止的 Y 轴盲走，`dir` 只能为 `-1` 或 `1`；任务与 TOF 映射仍会校验。 |
| `sf_descend` | `<task> <stop_mm> <max_pulses> <dir>` | 控制 | 独立执行 TOF3 Z 分段下降。 |
| `sf_grip` | `<task> <open\|close>` | 控制 | 独立执行夹爪动作并等待 C552 `APPLIED`。 |
| `sf_record` | `<task>` | 控制 | 记录当前有效且空闲的 XYZ 姿态。 |
| `sf_return` | `<task>` | 控制 | 返回最近一次已记录姿态。 |
| `sf_safe_set` | `<task> <x> <y> <z>` | 配置 | 设置指定任务的安全回归位置并保存到 EEPROM。 |
| `sf_retreat` | `<task>` | 控制 | 执行安全撤离；`tag_put` 顺序 Y/Z/X，其余为 Z/X/Y。 |

独立 P6 命令在 P7 任务活动期间会被拒绝。子流程启动响应只说明开始请求被接受，完成情况
必须通过 `sf_status` 判断。

## 12. TCP 5000 是独立控制入口

当前 `192.168.137.10:5000` 使用逐行 `OK/ERR` 协议，通过 RTOS 队列调用公开业务 API，
不调用本文件所述的 Shell parser，也不截获 USART1 的 `printf`。V1 只开放系统状态、P7
任务、任务取消、全局急停、逻辑载荷和任务配置查询；手动轴、标定、P6 板测和 PD42S1
底层命令仍只允许通过 USART1 调试。

完整定义见 `docs/socket控制协议.md`。
