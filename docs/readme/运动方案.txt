STM32H743 龙门架运动控制与安全方案 V2.1
=======================================

更新时间：2026-08-16
关联文档：../接替者阅读顺序.md、../legacy-migration-status.md、../C552通信协议v3.md

当前实现摘要：`red_pick`、`red_find`、`tag_put` 已完成实机正常完整流程，`frame_put`
仍待通过。本文件保留分层控制和安全设计原则；实际状态机、传感器映射、重试次数和板测结论
以 `legacy-migration-status.md` 及当前源码为准。


1. 目标和原则

系统为 XYZ 三轴龙门架，三个轴允许独立运动，不要求末端严格沿直线轨迹运行。

控制系统必须满足：

- 电机驱动器负责快速速度环和电流环。
- H743 负责位置目标、轨迹限制和外部传感器修正。
- C552 提供已滤波的 TOF 和 K230 观测。
- H743 只使用通过观测可信度检查的数据。
- 任一异常都不能形成无限累积或突然的大位移命令。
- 故障恢复后不自动续跑故障前的运动。


2. 分层控制结构

2.1 驱动器内环

执行位置：电机驱动器。
典型周期：1~5 ms。

职责：

- 执行速度、位置或电流命令。
- 抑制快速扰动。
- 执行驱动器自身过流、堵转和硬件故障保护。

H743 不重复实现驱动器内部电流环。


2.2 H743 位置和轨迹层

建议初始周期：20 ms，必须保持固定周期。

职责：

- 读取编码器或驱动器实际位置和状态。
- 生成受速度、加速度和软件行程限制的设定值。
- 计算位置误差并生成受限输出。
- 检查反馈年龄、跟随误差和驱动器故障。

历史 axis.c 已退出 Keil 编译和运行路径，不再作为位置层基础。新的 PID/运动控制模块应按
固定 20 ms 周期运行，并直接调用 smd.c/.h 的 PD42S1 底层接口。正式实现前必须测量
FDCAN 125 kbit/s 下的反馈周期、往返延迟和总线占用，确认反馈与命令接口不会阻塞控制周期。


2.3 H743 视觉和 TOF 外环

建议初始周期：40 ms。

职责：

- 读取滤波方案_H743端发布的 last_accepted_observation。
- 根据视觉中心、角度和 TOF 距离生成 XYZ 目标修正。
- 对每轴修正实施死区、速度限制、加速度限制和增量钳位。
- 数据可疑或不可用时冻结相关外环。
- 缓慢更新位置层目标，不能直接驱动电机硬件。

C552 每 20 ms（50 Hz）发送一次快照。外环不能在每次 UART/DMA 回调中运行，也不能
把相同 SAMPLE_SEQ 的重复快照当成新的控制输入。


3. 运动模式和传感器依赖

必需设备必须按运动模式配置，不能固定要求四个设备全部在线。

建议初始依赖关系：

手动运动：不依赖 K230；是否依赖 TOF 由机械安全要求决定。
TOF 距离运动：只要求相关 TOF 可用。
单视觉运动：只要求当前使用的 K230 和必要 TOF 可用。
双视觉融合：要求两个 K230 和必要 TOF 可用。
回零：主要依赖驱动器回零和限位状态，不依赖 K230 目标。

当前工程不使用固定 TOF1+TOF2 全局掩码。空闲默认只要求 K230_1；进入自动任务后由
`motion_coordinator` 按子流程动态切换：`red_pick`/`red_find` 的BlindMoveY要求TOF2，
`tag_put` 的BlindMoveY要求TOF1，`frame_put` 的Z下降要求TOF3。K230 无目标超过150 ms
后为 VALID=0、STALE=1，只终止或冻结依赖它的动作，不直接产生全局急停锁存。

若正在执行明确依赖 K230 的视觉动作，K230 无目标时应停止该动作或受控减速；这属于
业务目标丢失，不是 C552 链路故障。恢复后必须重新确认目标并创建新动作。


4. 观测接入条件

运动层不得直接读取最新通信快照，只能读取 H743 观测层发布的可信观测。

每个被当前模式依赖的设备必须满足：

1）C552 链路在线；
2）VALID=1、STALE=0；
3）effective_age_ms 未超过阈值；
4）协议值合理；
5）观测状态为 NORMAL；
6）last_accepted_observation 未超时。

固定阈值：

TOF stale：500 ms
K230 stale：150 ms
C552 链路超时：50 ms

FRAME_SEQ gap 只保留为通信质量诊断。当前帧 CRC 正确且设备观测新鲜时，gap 不直接
触发停止。设备的新数据判断以各自 SAMPLE_SEQ 为准。


5. TOF 控制策略

FILTERED_MM 用于正常距离控制。

MIN3_RAW_MM 用于近距离保守保护：

- 小于接近警戒阈值时，禁止继续向障碍物方向增加目标。
- 小于停止阈值时执行受控停止；只有达到硬安全边界时才立即停止。
- 距离恢复时使用回差，避免 MIN3 历史值导致状态反复切换。
- MIN3 不进入正常 PID，不替代 FILTERED_MM。

TOF1 和 TOF2 的几何含义、安装偏差和交叉一致性门限必须在标定后确定。


6. K230 控制策略

- CENTER_X、CENTER_Y 相对标定中心计算误差。
- 中心区域设置死区，避免静止目标附近反复微动。
- X_ROTATION、Y_ROTATION 使用最短环形角差。
- 像素误差和角度误差先转换为物理或归一化修正，再进入目标限制器。
- K230 无目标时冻结视觉修正，不保留积分推动目标继续移动。
- 目标重新出现后必须基于新的 SAMPLE_SEQ 完成 RECOVERING 确认。


7. 增量式 PID

如位置层采用增量式 PID，可使用：

delta_u(k) = Kp * [e(k) - e(k-1)]
           + Ki * e(k)
           + Kd * [e(k) - 2*e(k-1) + e(k-2)]

u(k) = u(k-1) + delta_u(k)

推荐让输出表示受限速度目标。若驱动器接口只能接收位置命令，必须先经过轨迹生成器，
不能把未经限速的累计输出直接作为新的绝对位置。

PID 必须具备：

- 最终输出限幅；
- 防积分饱和；
- 无效或 SUSPECT 数据时冻结积分；
- 恢复时重置历史误差，实现无扰接入；
- 对测量微分进行低通处理；
- 固定周期运行，不能由串口帧到达时间驱动。


8. 观测异常处理

每个设备由观测层维护 UNAVAILABLE、RECOVERING、NORMAL、SUSPECT、FAULT。

NORMAL -> SUSPECT：

- 新的独立样本相对运动预测发生明显突变。
- 单个传感器与其他观测短暂不一致。

进入 SUSPECT 后：

- 不采用可疑值更新目标。
- 冻结相关外环及其积分。
- 位置层保持当前安全设定值或受控减速。

SUSPECT 后续判断：

- 回到原趋势：丢弃异常点并恢复 NORMAL。
- 多个独立样本稳定在新位置：按业务规则确认新目标，并受限接入。
- 持续离散、越界或矛盾：进入 FAULT。

运动中应使用观测创新量，不使用固定静态差值作为唯一门限：

innovation = actual_sensor_change - predicted_change_from_axis_motion


9. 三轴独立增量钳位

每个轴独立限制单次目标修正：

delta_axis = clamp(target_axis - actual_axis,
                   -delta_limit_axis,
                   +delta_limit_axis)

首轮可将每轴单次绝对增量上限设为 10 mm，但实际限制必须同时满足：

delta_limit_axis = min(10 mm, max_velocity_axis * dt)

还必须执行：

- 每轴最大速度；
- 每轴最大加速度；
- 必要时限制加加速度；
- 软件行程上下限；
- 编码器跟随误差限制；
- 机械限位和硬件急停。

每次外环都从当前实际位置和最新可信目标重新计算，不能在未完成的旧目标上无限追加
10 mm。三个轴独立限幅，不要求按空间向量等比例缩放。


10. 故障优先级

10.1 立即禁止相关运动

- C552 合法帧超过 50 ms 未更新；
- 当前模式的必需设备无效、过期或观测为 FAULT；
- 编码器反馈超时；
- 驱动器严重故障；
- 软件行程越界、硬限位或硬件急停；
- 控制器状态损坏、溢出或非有限值。

10.2 冻结外环并观察

- 新观测进入 SUSPECT；
- 短暂的多传感器不一致；
- 视觉目标短暂丢失；
- 创新量轻微超限但未触及硬边界。

10.3 K230 无目标

- 设置对应 K230 警示和 UNAVAILABLE。
- 冻结依赖该 K230 的视觉外环。
- 不将 C552 链路标记为故障。
- 不停止手动或不依赖该 K230 的运动。
- 视觉动作根据业务要求受控停止，不执行全局立即急停。


11. 停止与恢复

普通传感器异常优先受控减速停止。
硬限位、严重驱动器故障、严重位置失控和硬件急停使用立即停止。

停止后：

- C552 DMA、协议解析和观测状态机继续运行。
- 编码器和驱动器状态监测继续运行。
- 保存停止原因和最近观测历史。
- 恢复后重新确认传感器、编码器和控制器状态。
- 不自动继续故障前的运动任务。


12. 历史和诊断

每个设备保存最近 16 个独立 SAMPLE_SEQ 观测。V2 聚合快照为 50 Hz，因此 H743 可见的
16 个观测最多覆盖约 320 ms；具体覆盖时间取决于设备实际更新率。

诊断至少包含：

- 新独立样本数和重复快照数；
- SAMPLE_SEQ 跳变；
- 当前和最大 effective_age_ms；
- NORMAL/SUSPECT/FAULT/RECOVERING 转换次数；
- 拒绝原因；
- FRAME_SEQ gap、CRC 和 UART/DMA 计数。

诊断统计不能直接替代实时控制许可条件。


13. 当前工程限制

- axis.c、servo.c、stepper.c 仅保留为历史源码，未加入 Keil 编译，也不在 main 和 Shell 中使用。
- 当前只有 smd.c/.h 提供底层 PD42S1 电机接口，尚未实现新的 PID/运动状态机。
- main.c 已不再通过 axis_stop_all() 执行 C552 故障停机；新控制模块必须在电机投入运动前补齐该安全责任。
- PID 内部位置单位和分辨率尚未确定，精细外环不应直接采用整数毫米。
- Y 轴行程尚未标定。
- 舵机和DRV8825软件输出当前均不参与运行。
- 正式闭环前必须测量 FDCAN 反馈周期、延迟和丢失情况。


14. 实施顺序

第一阶段：观测管理和记录

1）实现 SAMPLE_SEQ 去重和 effective_age_ms。
2）实现每设备 16 项独立样本历史。
3）通过 Shell 导出更新率、年龄、变化量和拒绝原因。
4）采集静止、运动、遮挡、目标移动和断线数据。

第二阶段：观测可信度

1）实现 NORMAL/SUSPECT/FAULT/RECOVERING。
2）确定静止噪声、动态创新量和多传感器一致性阈值。
3）实现按运动模式配置的 required sensor mask。

第三阶段：位置与轨迹层

1）测量并改造电机反馈路径，使控制周期固定。
2）实现速度、加速度、行程和每轴增量限制。
3）实现 PID 限幅、防饱和、冻结和无扰恢复。

第四阶段：视觉和 TOF 外环

1）只读取 last_accepted_observation。
2）按 40 ms 固定周期生成缓慢修正。
3）完成 TOF MIN3 近距离保护。
4）完成 K230 目标丢失、重新捕获和模式依赖测试。


15. 第一版参数汇总

C552 快照周期：20 ms（50 Hz）
C552 链路超时：50 ms
TOF stale：500 ms
K230 stale：150 ms
位置层建议周期：20 ms
外环建议周期：40 ms
独立观测历史：每设备 16 项
每轴单次增量上限：初始 10 mm，同时受速度和加速度限制
必需设备：由 `motion_coordinator` 按 owner 和当前子流程动态设置
K230 无目标动作：警示并冻结相关视觉外环，不执行全局急停
