十八、BOOT0 特别注意
================================================================================
BOOT0 在 CubeMX 中设为 GPIO_Input + Pull-DOWN
实际硬件: 电阻下拉到 GND, 跳线帽可选上拉到 3.3V
              正常运行时跳线帽不接 → BOOT0=0 (从Flash启动)
