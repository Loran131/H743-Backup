第一版传感器数据滤波建议
========================

版本：V1.0
适用系统：STM32C552 传感器板 + STM32H743 运动控制板


一、目标

1. 去除 TOF 和 K230 数据中的单点毛刺及小幅抖动。
2. 不把无效、过期或重复的传感器数据送入滤波器。
3. 控制滤波延迟，避免影响避障和运动控制响应。
4. C552 负责基础信号处理，H743 负责通信健康和运动安全判断。
5. 保留原始数据和诊断计数，便于后续调整参数。


二、推荐数据链路

传感器产生新测量
    -> C552 有效性检查
    -> 3 点中值滤波
    -> EMA 指数平滑
    -> 更新滤波结果、采样序号和采样时间
    -> C552 每 20 ms 发送一次最新快照
    -> H743 校验帧、序号、valid、stale 和 age
    -> 运动控制读取可信的过滤结果


三、两块 MCU 的职责

1. STM32C552

- 判断传感器原始数据是否有效。
- 识别无目标、超量程和协议哨兵值。
- 只在传感器产生新测量时更新滤波器。
- 执行中值滤波和 EMA。
- 维护每个传感器的 sample_seq、sample_tick、valid 和 stale。
- 每 20 ms 发送最新传感器快照。
- 保留原始值、拒绝次数和恢复次数供调试使用。

2. STM32H743

- 校验帧头、长度、设备 ID 和 XOR/CRC。
- 检查通信帧序号和链路超时。
- 检查各传感器 valid、stale 和 sample_age。
- 不重复执行同类 EMA，避免延迟叠加。
- 根据运动状态执行限速、停车和安全互锁。
- TOF 紧急停车可使用可信的快速距离通道，不完全依赖平滑结果。


四、发送周期和带宽

建议 C552 发送周期：20 ms（50 Hz）
当前协议帧长度：30 字节
串口配置：115200，8N1

单帧在线时间：

30 字节 x 10 bit / 115200 ≈ 2.60 ms

20 ms 周期下总线占用率约为 13%，有足够的 DMA、中断和方向切换余量。

注意：20 ms 是通信快照周期，不是所有传感器的采样周期。滤波器只能在对应
传感器获得新测量时更新，不能把重复发送的旧值当作新样本反复滤波。


五、推荐协议字段

每类传感器至少需要：

- filtered_value：过滤后的值。
- valid：当前数据是否有效。
- stale：当前数据是否过期。
- sample_seq：传感器新测量序号。
- sample_age_ms：发送时该测量已经存在的时间。

调试版本建议额外保留：

- raw_value：最新原始值。
- accepted_count：接受的样本数。
- rejected_count：拒绝的异常样本数。

如果当前 30 字节协议无法容纳全部字段，第一阶段至少保留 filtered_value、valid、
stale 和 sample_seq；原始值可以通过调试命令单独查询。


六、公共滤波状态

每个独立信号维护一份状态：

typedef struct
{
    float filtered;
    float median_buf[3];
    uint32_t last_sample_tick;
    uint32_t accepted_count;
    uint32_t rejected_count;
    uint8_t median_count;
    uint8_t initialized;
    uint8_t valid;
} FilterState;

建议分别建立：

- TOF1 distance
- TOF2 distance
- K230_1 center_x、center_y、degree_x、degree_y
- K230_2 center_x、center_y、degree_x、degree_y


七、滤波处理顺序

1. 检查传感器驱动是否报告新测量。
2. 检查 valid、错误码、量程和哨兵值。
3. 检查相邻样本变化是否超出物理允许范围。
4. 无效样本只增加 rejected_count，不更新滤波状态。
5. 对有效样本执行 3 点中值滤波。
6. 对中值结果执行 EMA。
7. 更新 sample_seq、sample_tick 和 filtered value。
8. 根据最后一次有效新测量的时间更新 stale。

EMA 公式：

filtered = filtered + alpha x (sample - filtered)

首次有效样本应直接赋值给 filtered，不能从 0 缓慢收敛。


八、第一版参数

1. TOF1、TOF2

- 中值窗口：3
- EMA alpha：0.25
- 恢复条件：连续 3 个有效新样本
- stale 时间：建议为传感器正常采样周期的 3 至 5 倍
- 输入范围：根据传感器实际规格确定
- 必须确认 8190、8191 等接近量程上限的值是否为无目标/超量程哨兵值

2. K230 中心坐标

- 中值窗口：3
- EMA alpha：0.25
- 恢复条件：连续 3 个有效新检测结果
- stale 时间：建议为实际图像输出周期的 3 倍
- 无目标或置信度不足时立即标记 invalid，不更新滤波器

3. K230 角度

- 中值窗口：3
- EMA alpha：0.20
- 对存在 180/360 度回绕的角度，必须先做环形角度差计算，再执行 EMA
- 如果角度只在有限小范围内变化，可以先使用普通 EMA

4. C552 到 H743 通信

- 发送周期：20 ms
- 建议链路超时：80 ms
- 链路恢复：连续 3 个有效帧
- 帧序号每发送一帧增加 1，而不是每次主循环增加


九、无效和恢复状态机

UNINITIALIZED：

- 没有可信输出。
- 收到第一个有效新样本后直接初始化 filtered。

VALID：

- 正常执行中值和 EMA。
- 更新 sample_tick 和 sample_seq。

TEMPORARY_LOST：

- 短暂没有新数据时可保留最后结果。
- 必须增加 sample_age，不能继续标记为新数据。

STALE/INVALID：

- 超过 stale 时间后 filtered_valid 置 0。
- 运动控制不得继续使用旧值做正常控制。
- 不清零 filtered，避免恢复时产生从 0 开始的跳变。

RECOVERING：

- 连续 3 个有效新样本后恢复 VALID。
- 恢复时可以使用最新中值重新初始化 EMA，避免旧状态污染。


十、TOF 安全通道

普通定位和显示使用 filtered_distance。

如果 TOF 用于防撞，不能让 EMA 延迟突然靠近的障碍物。建议二选一：

方案 A：

- 距离减小时使用较大的 alpha，例如 0.6。
- 距离增大时使用正常 alpha，例如 0.25。

方案 B：

- 正常控制使用 filtered_distance。
- 紧急停车使用最近 3 个可信原始距离的最小值。

第一版优先推荐方案 B，逻辑更清晰，安全行为更容易验证。


十一、异常跳变门限

门限必须根据实测数据和机械速度确定，不能直接猜固定数值。

建议形式：

max_delta = base_noise_margin + max_physical_rate x delta_time

如果样本变化超过 max_delta：

- 单次异常：拒绝并增加 rejected_count。
- 连续多次同方向异常：认为目标确实发生快速变化，重新初始化或放宽门限。

这样可以去除孤立毛刺，又不会永久拒绝真实的快速运动。


十二、首轮数据采集

实施滤波前，分别记录以下场景的原始数据、时间戳和状态：

1. 静止目标 30 秒。
2. 目标缓慢靠近和远离。
3. 目标快速进入和离开量程。
4. 无目标和超量程状态。
5. 遮挡、反光和边缘目标。
6. K230 静止目标、缓慢移动和快速移动。
7. 通信断开、恢复和丢帧。

日志至少包含：

tick, sensor_id, sample_seq, raw, filtered, valid, stale, accepted, rejected


十三、验收标准

1. 静止目标下，过滤后峰峰值明显小于原始值。
2. 单点毛刺不会直接进入过滤结果。
3. 真实阶跃变化能在可接受时间内跟随。
4. 无效和 stale 数据不会更新滤波器。
5. 断线后在规定时间内置 invalid 并禁止运动。
6. 恢复后不会从 0 缓慢爬升，也不会继承很久以前的旧状态。
7. 紧急靠近时，安全停车通道不因 EMA 产生明显延迟。
8. C552 20 ms 连续发送时，H743 的 UART ORE、DMA err 和 restart_fail 不持续增加。


十四、推荐实施顺序

第一步：确认各传感器真实采样周期和无效值定义。
第二步：增加 sample_seq、sample_tick、raw 和诊断日志。
第三步：实现 valid/stale 状态机，不做平滑。
第四步：加入 3 点中值滤波。
第五步：加入 EMA，并根据静态数据调整 alpha。
第六步：实现 TOF 快速安全通道。
第七步：C552 改为每 20 ms 发送一次快照。
第八步：H743 链路超时调整为 80 ms，并验证断线停车。
第九步：完成运动框架后再根据实际控制响应微调滤波参数。


十五、第一版默认配置汇总

C552 发送周期：20 ms
H743 链路超时：80 ms
中值窗口：3
TOF EMA alpha：0.25
K230 坐标 EMA alpha：0.25
K230 角度 EMA alpha：0.20
有效恢复帧数：3
TOF 安全值：最近 3 个可信原始值的最小值

这些参数只是第一版起点，最终数值必须由原始数据日志和运动响应共同确定。
