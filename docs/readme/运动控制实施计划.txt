一、目标和边界
--------------

本计划用于把当前工程逐步整理为：

1. X轴：PD42S1，FDCAN2，电机地址1，丝杠传动；
2. Y轴：PD42S1，FDCAN2，电机地址2，齿轮传动；
3. Z轴：独立MCU控制DRV8711，H743通过UART4发送17字节二进制帧；
4. C552：负责TOF、K230和夹爪，H743按任务模式选择需要的数据；
5. USART1：初期作为人工调试、任务下发、接收ACK和校准入口；
6. axis.c、servo.c、stepper.c、buzzer.c保留在磁盘，但不作为当前控制架构；
7. 自动任务只有在坐标有效、校准参数有效和必需传感器READY时才能执行。

不在本计划中继续使用旧axis.c的人类友好绝对坐标状态机。新的运动层只服务PID、任务状态机、
轨迹限制和安全停止，底层分别调用SMD和Z轴串口协议。


二、已知轴参数和待确认项
----------------------

轴  底层/地址       传动方式  当前推荐速度          当前可确认的单位       状态
X   PD42S1/ID=1     丝杠      3000                  RPM                  暂定，需测量
Y   PD42S1/ID=2     齿轮      5~10                  RPM                  暂定，先从5开始
Z   UART4/DRV8711   STEP/DIR  1,000,000 Hz（用户值） STEP脉冲频率          与协议冲突

现有smd.c已明确：相对位置函数speed_rpm范围为0~3000 RPM，pulses为脉冲数，
51200脉冲等于电机一圈。因此X=3000和Y=5~10的单位就是RPM，不是未知单位。

Z轴协议当前声明SPEED范围为1~100000 Hz，而计划速度为1 MHz，超出协议上限10倍。
P2实现前必须确认以下三者中的哪一个需要修改：

1. 1 MHz是否为笔误；  是。应该为0.1MHZ。

在这一问题确认前，H743端不固化Z轴默认速度，也不发送1 MHz命令。

还需确认：

- X/Y/Z正方向与机械坐标正方向；  X：正转 向位移增大的方向移动 反转向位移零点（机械限位）移动。
 
- X/Y的DIR=0/1分别对应哪个机械方向；
- Z的CW/CCW分别对应上升还是下降；
- X/Y每毫米脉冲数；
- Z每毫米STEP数；
- 三轴软件行程上下限；
- X/Y正常运行加速度和回零加速度； 我们平常调试使用的是相对运动函数，速度一直使用前文推荐速度。这个很重要吗（）
- X/Y回零堵转电流、回零速度和退让距离。



三、模块目标结构
----------------

USART1 Command Manager
    -> 接收模式命令、校准命令、ABORT和状态查询
    -> 分配transaction_id
    -> 返回ACCEPTED/REJECTED/COMPLETED/FAILED

Mission FSM
    -> 管理四个外部任务模式
    -> 复用抓取、对正、盲走、夹爪、验证和回撤子状态

Motion Controller
    -> 固定周期运行
    -> 管理三轴状态、软限位、超时、堵转和安全停止
    -> XY调用xy_motor，Z调用z_axis_link

xy_motor.c/.h
    -> X固定映射PD42S1地址1
    -> Y固定映射PD42S1地址2
    -> 不提供可任意输入地址的自动控制API

z_axis_link.c/.h
    -> UART4 115200 8N1
    -> 17字节固定帧、CRC16/MODBUS、小端整数
    -> 单命令在途，管理接受ACK和完成ACK

calibration.c/.h
    -> Z人工零点
    -> 姿态示教
    -> 相机像素中心和轴映射
    -> TOF参考距离
    -> EEPROM参数版本和CRC

c552_link / observation
    -> 20 ms主从请求/响应
    -> 传感器配置、READY、固定快照和夹爪状态

P0 需求与接口冻结

工作：
- 固定三轴编号、单位和正方向；
- 固定USART1任务命令与ACK语义；
- 补齐Z轴STOP、QUERY_STATUS、CLEAR_FAULT协议；
- 确认Z轴最高STEP频率；
- 确认四种任务的名称和外部命令编号。

解决的问题：
- 无停止命令时，Z轴无法响应ABORT或安全故障；
- Z协议没有事务号，必须限制为单命令在途；
- 1 MHz与100 kHz协议上限冲突；
- STATUS=02时SPEED/STEPS字段如何填写尚未定义。

完成条件：协议和接口文档不再有单位、范围或停止语义歧义。

P2 Z轴二进制协议层

工作：
- 实现CRC16/MODBUS；
- 实现命令帧编码；
- 实现固定17字节滑动同步解析器；
- 实现UART4非阻塞接收；
- 管理STATUS=00接受、01完成、02~06错误；
- 记录请求速度、请求步数、完成步数和应答年龄；
- 实现超时、重同步和错误统计。

解析顺序：
寻找AA 55 -> 等待17字节 -> LEN必须为0A -> 帧尾必须为0D 0A
-> CRC覆盖LEN+CONTENT共11字节 -> CMD必须为81 -> 解析STATUS。

固定测试向量：
AA 55 0A 01 00 D0 07 00 00 00 19 00 00 DC A2 0D 0A

完成条件：正确帧、CRC错误、错位帧、分段到达、连续两帧、接受ACK、完成ACK和故障ACK测试通过。


P3 X/Y电机接口和Shell整理

工作：
- 定义X地址1、Y地址2为唯一常量；
- 建立薄层xy_motor.c/.h，只做轴到地址映射和参数检查；
- 自动控制API不再暴露addr参数；

建议初期Shell：

y_rel <dir> <acc> <rpm> <pulses>
x_stop / y_stop
x_pos / y_pos

完成条件：所有X命令只访问ID1，所有Y命令只访问ID2，输入越界不会下发CAN帧。


P4 三轴状态和安全层

工作：
- 每轴维护UNREFERENCED、IDLE、MOVING、STOPPING、FAULT；
- 维护命令目标、开始时间、最后反馈、当前位置和故障码；
- 实现软限位、命令超时、反馈超时和统一ABORT；
- 区分回零预期堵转与普通运动异常堵转；
- 普通堵转后反向低速退让，但不自动继续原任务；
- X/Y堵转恢复后重新回零；Z故障后重新人工确认零点。

完成条件：任意任务阶段都能停止；故障恢复不会自动续跑旧命令。


P5 校准、示教和参数存储

示教槽位至少包括：
- RED_OBSERVE；
- TAG_OBSERVE；
- FRAME_OBSERVE；
- SAFE_RETREAT。

EEPROM内容必须有magic、结构版本、长度和CRC。观察姿态、映射和TOF偏移可以跨上电保存；
Z_REFERENCED只代表本次上电是否人工确认，不能从EEPROM自动恢复为有效。

完成条件：参数损坏时拒绝自动任务；人工示教后可保存、读取并重复到达相同姿态。

P8 四任务状态机

模式1/3红色抓取：
PRECHECK -> RED_OBSERVE -> FRONT_RED_READY -> ALIGN_XZ -> STABLE
-> RECORD_XYZ -> BLIND_Y -> GRIP_CLOSE -> RETURN_RECORDED_POSE
-> VERIFY_RED_COUNT -> COMPLETE或有限次数RETRY。

模式2 AprilTag放置：
PRECHECK_HELD -> TAG_OBSERVE -> FRONT_TAG_READY -> ALIGN_XZ -> STABLE
-> BLIND_Y -> OPTIONAL_Z_DROP -> GRIP_OPEN -> SAFE_RETREAT -> COMPLETE。

模式4红框放置：
PRECHECK_HELD -> FRAME_OBSERVE -> DOWN_FRAME_READY -> ALIGN_XY -> STABLE
-> TOF3_Z_DESCEND -> GRIP_OPEN -> SAFE_RETREAT -> COMPLETE。

每个状态必须定义进入动作、完成条件、超时、必需传感器和失败动作。


P9 USART1任务和ACK

最少结果：
- ACCEPTED：参数合法且任务已入队；
- REJECTED：未开始，原因如BUSY、NOT_HOMED、NOT_CALIBRATED；
- COMPLETED：整个任务成功；
- FAILED：任务已开始但故障终止。

必须携带transaction_id。重复事务号只能重发原结果，不能再次启动。另设ABORT和QUERY_STATUS。


P10 整机联调

顺序必须是单通信、单轴低速、单轴全行程、回零、校准、PID、单任务、四任务连续运行。
禁止第一次测试就同时运行三轴或直接执行完整抓放。


五、从哪里开始测量：最小测量顺序
--------------------------------

不要一次测完所有参数。每完成下面一项就记录并冻结该项，再进入下一项。

M1 只验证通信，不接机械负载运动
- UART4 TX/RX交叉接线、共地、电平；
- 发送固定17字节样例，确认Z轴MCU返回STATUS=00；
- 人为改一个CRC字节，确认STATUS=02或丢弃策略符合协议；
- 记录UART4单程和接受ACK延迟。

M2 三轴方向
- 每轴只走很小距离；
- 记录DIR=0和DIR=1对应的机械方向；x轴 dir=1 朝位移零点运动，x轴dir = 0朝远离位移零点的地方移动。y轴dir=0朝位移增加的方向移动，y轴dir=1朝位移零点移动。
- 在代码中固定X/Y/Z正方向； 均为远离零点为正
- 未确认方向前禁止回零和大距离命令。

M3 每毫米脉冲数
- X、Y分别命令固定脉冲，使用卡尺测实际位移；x轴1280000steps，运动约9.5cm，3000rpm下约1.84s（包括响应到停止运动，人工测量存在误差）。y轴1024000steps，运动12.5cm，15rpm（注意这是最高速度不能再快了，再快起飞）。
- 至少测正向和反向各3次；
- 计算平均脉冲/mm和反向间隙；
- Z使用同样方法测STEP/mm；
- 不要只用电机理论步距代替机械实测。

M4 软件行程
- 人工低速移动到两端安全位置；
- 测量总可用行程；
- 两端各保留机械余量；
- 保存X/Y/Z软件最小值和最大值；
- 正常命令在发送到底层前必须先检查目标位置。

M5 速度和加速度
- X从较低RPM逐步增加到3000，记录振动、噪声、停止距离和是否丢步；
- Y从5 RPM开始，测试5、6、8、10，不直接跳到更高值；
- 每个速度至少完成10次往返；
- 记录人眼可接受速度不等于PID可用速度，PID对正通常需要更低的精调速度；
- 为每轴分别保存快速移动速度和PID精调速度。

M6 X/Y无限位回零
- 从低回零速度和低堵转电流开始；
- 测堵转触发是否稳定，不能用正常负载波动误触发；
- 记录触发电流、耗时和位置重复性；
- 堵转后反向退让固定距离；
- 连续回零10次，测零点离散范围；
- 最终参数必须保留机械余量。

M7 Z人工零点
- 制作肉眼容易重复的刻线、定位块或治具；
- 上电后低速pos_rel移动到该位置；
- 执行z_set_zero；
- 测试+5 mm、-5 mm并返回零点；
- 重复人工设零5次，记录误差；
- 误差满足抓放需求后再进入自动任务。

M8 相机与轴映射
- 固定观察姿态和相机分辨率；
- 人工把夹爪工作点对准目标，保存目标像素；
- 前视分别移动X、Z已知距离，记录像素变化；
- 下视分别移动X、Y已知距离，记录像素变化；
- 在近、中、远工作距离重复，判断是否需要分距离参数。

M9 TOF偏移
- 将夹爪移动到已知安全距离；
- 同时记录TOF读数和尺量真实距离；
- 每个TOF至少测5个距离点；
- 计算固定偏移、重复性和靠近边界时的误差；
- TOF1/2用于盲走距离估计，TOF3用于Z闭环，参数不能共用。

M10 单任务和整机
- 先不装物块执行空路径；
- 再使用软质障碍物和低速；
- 单独验证夹爪开闭；
- 单独验证抓取后回观察位；
- 最后验证失败重试和ABORT；
- 四模式连续运行后检查坐标是否累计漂移。

七、当前优先级和阻塞项
----------------------

当前状态：P1已完成，尚未开始P2。

P1完成后优先执行：
1. 确认Z轴1 MHz是否准确，以及是否修改100 kHz协议上限；
2. 给Z协议增加STOP和QUERY_STATUS；
3. 开始P2，仅实现组帧、CRC、解析和通信诊断，不立即驱动机械运动；
4. 用M1固定样例完成台架通信测试；
5. 再进入P3的X/Y命令整理。

最重要的原则：一次只解决一个可测问题。先确认通信，再确认方向，再确认比例，再确认行程和速度，
最后才做PID和完整任务。参数数量看起来很多，但按M1~M10执行时，每一步只需要测少量数据。
