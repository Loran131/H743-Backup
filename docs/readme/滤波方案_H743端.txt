STM32H743 传感器观测处理方案 V2.0
==================================

更新时间：2026-08-10
适用协议：C552 Sensor Hub -> H743 串口通信协议 V2.0


1. 目标

- 接收并使用 C552 已完成中值滤波和 EMA 的传感器结果。
- 不把重复快照、无效、过期或不合理的数据送入控制层。
- 用每个设备独立的 SAMPLE_SEQ 区分新测量和重复快照。
- 建立 H743 本地观测历史和可信度状态，支持实测调参和故障诊断。
- 只向运动控制发布最新的、经过确认的观测。


2. 两端职责边界

C552 负责：

- 原始传感器协议校验、设备 ID 检查和字段范围检查。
- TOF、K230 坐标的 3 点中值和 EMA。
- K230 角度的环形中值和环形 EMA。
- TOF 最近 3 个可信原始距离的最小值 MIN3_RAW_MM。
- 每设备 SAMPLE_SEQ、SAMPLE_AGE_MS、VALID 和 STALE。
- 连续 3 个独立有效样本后的恢复确认。

H743 负责：

- V2 帧同步、固定字段检查、CRC16 和本地链路超时。
- STATUS、SAMPLE_SEQ、SAMPLE_AGE_MS 和协议范围一致性检查。
- 独立样本去重、历史记录、突变和趋势判断。
- 根据当前控制模式决定哪些设备是必需设备。
- 将可信观测转换为受限的 XYZ 目标修正。

H743 不再对 C552 的 FILTERED、CENTER 或 ROTATION 重复执行同类中值和 EMA，
否则会叠加延迟。H743 对控制目标实施的死区、斜率限制和增量钳位不属于重复滤波。


3. 固定时间参数

C552 聚合快照周期：20 ms（50 Hz）
H743 C552 链路超时：50 ms
TOF stale：500 ms
K230 stale：150 ms
建议外环周期：40 ms

链路超时和设备 stale 是两类不同状态：

- 链路超时表示 H743 没有继续收到完整合法的 C552 帧。
- 设备 stale 表示 C552 链路仍正常，但某个传感器没有产生新的有效测量。

K230 无目标时不发送测量，超过 150 ms 后为 VALID=0、STALE=1。这是目标不可用，
不是 C552 通信故障，不触发全局急停。


4. 数据进入控制层的条件

每个设备必须同时满足以下条件才可进入观测处理：

1）C552 链路在线；
2）对应 VALID=1；
3）对应 STALE=0；
4）不存在 H743 协议范围不合理标志；
5）H743 计算的有效年龄未超过设备 stale 阈值；
6）观测可信度状态允许使用。

H743 有效年龄计算：

effective_age_ms = sample_age_ms + (now - snapshot.rx_tick)

加法必须执行饱和处理，最大为 65535。协议中的 SAMPLE_AGE_MS 只计算到 C552
构造快照的时刻，H743 的接收、排队和控制任务延迟必须由本地帧龄补入。


5. SAMPLE_SEQ 去重

每个逻辑设备独立维护 last_seen_sample_seq 和 initialized。

- 首个可检查样本只建立基准。
- delta=0 表示重复快照，不进入历史缓存，不累计恢复样本数。
- delta!=0 表示至少出现一个新传感器样本，处理当前最新观测。
- delta>1 可以记录为样本序号跳变，但不能直接判定通信故障。
- uint16 回绕必须使用无符号差值处理。

C552 可能在两个 20 ms 快照之间接受多个约 10 ms 的传感器样本，因此 H743 看到
SAMPLE_SEQ 一次增加 2 是正常情况。H743 只能处理快照中最新的一份观测。

FRAME_SEQ 只用于链路诊断。FRAME_SEQ gap 不直接拒绝当前 CRC 正确的快照，也不代替
设备 SAMPLE_SEQ。只要链路、STATUS 和有效年龄正常，FRAME_SEQ gap 不参与运动急停。


6. H743 协议合理性检查

TOF：

- FILTERED_MM 范围为 0~1600 mm。
- MIN3_RAW_MM 范围为 0~1600 mm。
- VALID=1 时 SAMPLE_AGE_MS 不得为 0xFFFF，且有效年龄不得超过 500 ms。

K230：

- CENTER_X、CENTER_Y 按 int16 接收；机械可用范围在标定后另行确定。
- X_ROTATION、Y_ROTATION 范围为 0~35999。
- VALID=1 时 SAMPLE_AGE_MS 不得为 0xFFFF，且有效年龄不得超过 150 ms。

任一设备出现 VALID=1、STALE=1 时按不可用处理，并记录状态不一致诊断。
协议合理性检查失败不得静默限幅后继续控制，原始快照应保留用于诊断。


7. TOF 使用规则

FILTERED_MM 用于正常距离判断和位置修正。

MIN3_RAW_MM 只用于保守的近距离辅助保护：

- 靠近安全边界时可用于冻结继续靠近的目标或触发受控停止。
- 不用于正常距离闭环，也不替代 FILTERED_MM。
- 远离物体时 MIN3 可能短时保留较小历史值，恢复阈值需要设置回差。

第一版不设置未经实测的固定突变拒绝门限。应先记录静止、靠近、远离和快速运动数据，
再根据噪声、最大机械速度、采样年龄和运动方向确定阈值。


8. K230 使用规则

- CENTER_X、CENTER_Y 相对标定中心计算像素误差。
- 中心附近设置死区，避免目标抖动造成电机反复微动。
- 角度误差使用 [-18000, 18000) 范围内的最短环形角差。
- K230 无目标时冻结对应视觉外环，不更新目标，不累计 PID。
- 手动运动和不依赖视觉的运动不因 K230 无目标而停止。
- 视觉依赖动作在 K230 失效时受控停止或等待重新捕获，不自动续跑旧动作。


9. 观测可信度状态机

每个逻辑设备建议维护：

UNAVAILABLE：VALID=0、STALE=1、年龄超限或链路不可用。
RECOVERING：收到新的独立样本，等待控制层确认。
NORMAL：观测可进入控制。
SUSPECT：观测突变或与预测短暂不一致，冻结该设备外环。
FAULT：连续异常，禁止依赖该设备的动作。

C552 已经完成连续 3 个原始样本的滤波恢复，H743 不应再按聚合帧重复做同一恢复。
H743 的 RECOVERING 用于控制模式重新接入、突变恢复和目标重新捕获，所有确认计数必须
基于新的 SAMPLE_SEQ，而不能基于收到的快照数量。

运动状态下不能只使用固定帧间差阈值。应比较：

innovation = actual_change - predicted_change_from_axis_motion

阈值至少考虑传感器噪声、有效年龄、轴速度、运动方向和编码器反馈延迟。


10. 独立样本历史

建议每个逻辑设备保存最近 16 个独立观测，而不是保存 16 个重复聚合快照。

每项至少包含：

- H743 接收时间和 effective_age_ms；
- SAMPLE_SEQ；
- 传感器值；
- STATUS；
- 接受或拒绝结果；
- 拒绝原因。

另外维护：

last_raw_observation：最新通过协议检查的观测。
last_accepted_observation：最新允许进入控制器的观测。

V2 聚合帧为 50 Hz，16 个 H743 可见观测最多覆盖约 320 ms，不再使用旧文档中
“200 Hz、16 帧约 80 ms”的计算。


11. 故障动作

立即禁止所有依赖 C552 的运动：

- C552 合法帧超过 50 ms 未更新；
- 必需 TOF 无效、过期或协议值不合理；
- 严重驱动器、编码器、限位或系统故障。

只冻结相关外环：

- K230 无目标或超过 150 ms stale；
- 单个观测进入 SUSPECT；
- 当前模式不依赖的设备不可用。

停止后 DMA、协议解析和状态监测必须继续运行。恢复后不自动继续故障前的运动。


12. 首轮实施顺序

1）实现每设备 SAMPLE_SEQ 去重和 effective_age_ms。
2）增加 16 项独立样本历史及拒绝原因。
3）通过 Shell 输出新样本数、重复快照数、年龄和状态统计。
4）采集静止与运动数据，确定坐标、角度、TOF 和创新量阈值。
5）实现 NORMAL/SUSPECT/FAULT/RECOVERING 状态机。
6）只向运动层发布 last_accepted_observation。
7）接入固定 40 ms 外环和受限目标生成。


13. 验证要求

- 相同 SAMPLE_SEQ 出现在多个快照时只处理一次。
- SAMPLE_SEQ 回绕不产生异常拒绝。
- SAMPLE_SEQ 跳变时接受当前最新样本，但保留诊断计数。
- effective_age_ms 超限后不再使用旧观测。
- K230 无目标 150 ms 后冻结视觉外环，但不产生整车通信故障。
- TOF FILTERED 用于正常控制，MIN3 只用于近距离辅助保护。
- CRC 错误、丢字节和粘包不会发布半更新快照。
- SUSPECT 和 FAULT 状态下不更新控制目标或 PID 积分。
